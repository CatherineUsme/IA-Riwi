# Medellin Mercado Mapa

Quiero crear una pagina web para mi marca: lole-app

Descripción negocio: es una pagina web en la que se recopila toda la información de las tiendas del centro de Medellín, ofrece principalmente dos servicios:

•	Búsqueda de comercios: si necesitas encontrar por ejemplo un electrodoméstico, la pagina te va a mostrar en un mapa del centro todos los comercios donde venden electrodomésticos, rankeando las tiendas por mejor puntuación en su relación precio-calidad. El obejtivo es que asi no conozcas al centro puedas encontrar siempre el mejor lugar para comprar.

•	Personal Shopper: muchas personas no les gusta bajar al centro, pero si comprar allá, mientras hay otras personas a las que les encanta andar el centro, la página reúne ambas el que necesita algo y el que puede ir a comprarlo.
